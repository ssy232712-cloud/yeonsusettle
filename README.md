# 대회 예산·정산 도우미 (yeonsusettle)

유소년 축구 대회의 예산 짜기 → 쓴 돈 기록 → 정산 → 정산표 PDF까지 순서대로 안내하는 웹앱입니다.

👉 바로 쓰기: https://ssy232712-cloud.github.io/yeonsusettle/

## 사용법
1. 링크를 열고 **새 대회 만들기**를 누릅니다. (예시로 먼저 둘러볼 수도 있어요)
2. 아래 메뉴 순서대로: **대회 → 예산 → 지출 → 정산 → 정산표**
3. 오른쪽 위 **저장하기**를 누르면 내 기기(브라우저)에 저장됩니다.
4. 정산표 탭에서 **PDF 저장 / PDF 공유**로 단톡방에 올립니다.

## 알아두기
- 입력한 내용은 **각자 기기에만 저장**되고 다른 사람에게 보이지 않습니다.
- 다른 기기로 옮기거나 백업하려면: 오른쪽 위 ⋯ → 백업 파일 받기 / 불러오기
- 구글시트로 관리: ⋯ → 구글시트 → 시트용 CSV 받기 → 구글시트에서 파일 › 가져오기
