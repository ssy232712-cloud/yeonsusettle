# 대회 예산·정산 도우미 (yeonsusettle)

유소년 축구 대회의 예산 작성부터 사용내역 기록, 정산, 정산표 작성까지 한 화면에서 하는 웹앱입니다.

- 바로 쓰기: https://ssy232712-cloud.github.io/yeonsusettle/
- 탭: 기본정보 · 예산 · 사용내역 · 정산 · 정산표
- 저장: 이 브라우저에 저장됩니다. 다른 기기와 나눌 때는 "구글시트" → 시트용 CSV 받기 → 구글시트에서 파일 › 가져오기
- 구글시트에서 고친 내용 반영: 구글시트에서 파일 › 다운로드 › CSV → 앱에서 "시트 CSV 불러오기"
